# LCTA 1.6.0 修改记录

## 对应需求

1. 悬浮入口沿用“边·译”图标，裁去黑底，保留中央缺口。
2. 表面不放关闭按钮，菜单保留关闭入口，可从主界面重新开启。
3. 服务预设共用模型配置，新增千问、Gemini、LM Studio，提供模型列表读取和手动输入。
4. 数据目录支持复制迁移；缓存、日志、导出、下载、证据、OCR 模型目录分别设置。
5. 缓存支持关闭、内存及可选磁盘、容量与期限、上下文隔离、命中统计和清理。

## 检查记录

Release 编译无警告或错误；161 项回归与 214 项交互检查通过。包含实际菜单关闭、透明裁切、无效路径不改配置、迁移后密钥与个人术语可读取、取消迁移、缓存失效与模型列表读取。测试使用独立配置、合成内容和模拟服务。

原始结果保存在源码工作区 `.artifacts/*-1.6-final.txt`，不提交临时配置或截图证据。安装、升级与便携包必须对当前构建执行 `tools/verify-release.ps1`。发布前须核对 SHA256 与公开下载文件。

## 数据与兼容性

- 源码维护目录：`X:\Codex\LCTA`；用户便携程序：`X:\LCTA`。
- 默认沿用旧设置，数据迁移由用户在支持页执行，原目录保留。
- 公共词库版本沿用 `2026.10.8.1`，本次未改动术语条目。
- API 测试不使用真实账户；读取模型列表不保证列出的全部模型支持文本聊天。
- 系统自身、安装器临时文件以及第三方模型服务的存储路径不受应用设置控制。

## 后续实测

真实边狱巴士与网页、在线服务的译文质量、混合 DPI 跨屏、独占全屏与长时间运行继续由实际环境反馈。新增原生运行库随完整发行目录分发，不支持只复制 EXE。
