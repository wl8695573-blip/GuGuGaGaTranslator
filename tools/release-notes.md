## 装完就能用

- **识别(认字)**:离线模型(PP-OCRv6,日/英/中通吃)随包附带,**不需要任何额外下载**,解压/安装即用。
- **翻译**:需要一个 API Key,**不用装软件**。第一次启动会弹出设置卡片,每个服务商都有可点开的领取链接和一行「拿 Key 的步骤」;填好后可以点「测试连接」当场验证。
  - DeepSeek 新账号通常有赠送额度,一句台词约 $0.00003
  - 想零成本可以选智谱的免费模型 `glm-4-flash`
- **没有 Key 也能先跑**:点「先跳过」,抓屏和识别照常工作,只是译文显示成 `[mock …]` 原文 —— 用来确认框选和认字对不对。

## 五分钟上手

1. 双击启动 → 第一次运行填 API Key(或用「先跳过」)
2. 主界面左列选中游戏窗口(没有就点「刷新列表」)
3. 点「底部对话框(一键)」自动框住对话框;想更精准就点「框选区域」自己拖,**Enter 确认**
4. 点「开始翻译」,译文实时贴在对话框上
5. 用控制条上的「🔒 编辑」解锁后可像 Word 文本框一样拖动缩放,调好再锁回

## 这一版有什么

- 窗口级抓屏 + 离线识别 + AI 翻译的完整闭环,一行新台词约 1 秒
- **游戏专属术语表**:指定作品后按官方译名翻译,译错了会被自动改回(可一键让 AI 起草)
- 悬浮层:遮盖原文 / 下方字幕 / 极简描边三种预设,可拖动缩放、可调透明度、鼠标穿透
- 对话区域只认台词:跳过 SAVE / LOAD 这类界面文字
- 识别 20 毫秒级跳帧判断,重复台词走缓存,不重复花钱
- 快捷键:开始/暂停/重新框选/解锁翻译框/原文/显隐翻译框

详细说明见 [README](https://github.com/wl8695573-blip/GuGuGaGaTranslator#readme)。

## 已知限制

- 游戏必须用「无边框窗口 / 窗口化全屏」;**独占全屏抓不到画面**,任何置顶悬浮窗也显示不出来 —— 这是抓屏类工具的共同限制。
- 程序未做代码签名,可能被杀软启发式误报;源码就在这里,可以自己构建(`.\build.ps1 -Publish -SingleFile`)。
