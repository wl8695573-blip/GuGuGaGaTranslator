# GuGuGaGaTranslator 1.3.0

本版本增加磁盘缓存、档案分享和诊断导出，修复接口、界面和安装卸载问题。

## 新功能

- 可选 SQLite 磁盘缓存，按当前 Windows 账户加密译文，支持保留天数、容量限制和清除。
- 游戏档案导入导出，包含版本、作者、来源和许可；导入后可编辑并保存为独立副本。
- 手动导出诊断 ZIP，包含版本、状态、计数和耗时，不包含台词、译文、截图或密钥。
- 界面中可配置和测试彩云、有道、百度，并显示各接口的能力差异。

## 修复

- 框选区域按客户区尺寸调整；修复术语复制丢失语言标签、无效语言选项和下拉框显示问题。
- 修复空配置字段导致的启动异常，以及后台通知可能造成的锁等待。
- 服务商扩展参数按地址发送，避免通用 OpenAI 兼容接口拒绝请求。
- 首次设置保留自定义接口和模型；切换服务时清除旧密钥，关闭窗口时取消连接测试。
- 修复卸载清单超过命令行长度、卸载失败退出码、首次创建快捷方式目录及中文路径快捷方式的问题。
- 重编使用说明和维护指南，统一代码格式，精简注释及界面文案。

## 下载与升级

- `GuGuGaGaTranslator-Setup-1.3.0.exe`：安装版。退出旧程序后安装到原登记目录。
- `GuGuGaGaTranslator-win-x64-1.3.0.zip`：便携版。完整解压到新目录并保留 `models` 等文件。
- `SHA256SUMS-1.3.0.txt`：下载文件的 SHA256。

适用于 Windows 10 2004（19041）及更高版本的 x64 系统，附带 .NET 运行时和 OCR 模型。配置保存在当前用户的应用数据目录；更换电脑或账户后需重新填写密钥。

发行包未进行代码签名。识别效果和抓屏兼容性取决于字体、布局、窗口模式和系统；合成样本检查不能保证所有游戏均可使用。在线翻译需要用户自己的凭据或本地服务。
