# GuGuGaGaTranslator 1.3.2

本版本修复外观预设闪退、悬浮控制条无法拖动和关闭，以及翻译框遮住识别区域的问题。

## 修复与调整

- 保留四种外观预设，修复选择后重复触发事件导致的崩溃；修改外观时保留其他尚未保存的设置。
- 控制条左侧新增拖动柄，拖动时翻译框跟随移动；右侧“×”关闭整个悬浮层并停止翻译。可在主界面重新开始。
- 修复关闭后残留控制条、收到迟到译文后再次弹出，以及停止后立即重启的问题。
- 默认使用 Windows 窗口捕获。翻译框或其他窗口盖在识别区域上时，仍读取目标窗口的原文，不把译文重新识别进去。
- 识别设置提供窗口捕获、屏幕捕获和 PrintWindow。首次升级会把旧版默认屏幕捕获改为窗口捕获；之后保留手动选择。
- 翻译框保持在显示器工作区域内，长内容可在“编辑”模式下滚动；修正上方放置时的拖动方向。

## 下载与升级

- `GuGuGaGaTranslator-Setup-1.3.2.exe`：安装版。退出旧程序后安装到原登记目录。
- `GuGuGaGaTranslator-win-x64-1.3.2.zip`：便携版。完整解压到新目录，不要只复制 exe。
- `SHA256SUMS-1.3.2.txt`：下载文件的 SHA256。

适用于 Windows 10 2004（19041）及更高版本的 x64 系统，附带 .NET 运行时和 OCR 模型。配置保存在当前用户的应用数据目录，升级保留密钥与术语设置。启动后确认程序版本为 1.3.2。

## 验证范围

本机通过 54 项回归与 86 项交互检查，包括运行中切换四种外观预设、拖动、关闭、重启、完整窗口遮挡、译文重叠、目标窗口移动和缩放。RapidOCR 的 27 张固定样本全部通过。完整流程使用实际窗口捕获、RapidOCR 与 mock 翻译验证，不产生在线翻译费用。

窗口最小化、游戏停止渲染、受保护内容和独占全屏可能无法提供有效画面；遇到兼容问题可切换屏幕捕获，并保持识别区域无遮挡。录屏中是否显示译文由“对录屏/截图隐藏”控制。

发行包未进行代码签名。不同游戏与在线服务的兼容性仍需按实际环境确认。
