# GuGuGaGaTranslator 1.2.0

本次更新集中修复翻译卡住、旧译文滞后、OCR 资源释放和安装卸载问题；语言范围收窄为中 / 日 / 英三语互译，并内置调好的《边狱巴士》术语表。

## 语言与术语表

- **只保留中 / 日 / 英三种语言**，六种方向都能互译（日→中、英→中、中→日、中→英、日→英、英→日）。翻译方向与识别语言列表都只剩这三种，旧配置里的其他语言读取时自动回退。
- **术语表支持一张表装多种原文**：行首写 `en:` 或 `ja:`。译成中文取源语言那一列，中文译成外语反过来用，两种外语互译时以中间的中文译名自动配对；不写语言的行按“任意外语 → 中文”处理，旧表照旧可用。
- **装完自带调好的《边狱巴士》档案**：253 条术语（英文 194 条、日文 59 条），以零协会汉化译名为基准，世界观与语气一并配好。日文原文里「罪人」写作「囚人」、「异想体」写作「幻想体」、「扭曲」写作「ねじれ」这类差异都已处理。
- 术语强制校正随方向生效：译成中文时纠正中文错译（奥德修斯→奥提斯、N社→N公司、唐吉诃德→堂吉诃德），译成日语或英语时把漏译的原文改回目标语言写法。
- 修正内置术语把「九人会」写成「新九人会」的错误。

## 本次修复

- OCR 与网络翻译分开运行；新台词取消过期翻译，慢请求不再阻止下一次识别。
- 修复超时后停止翻译、流式读取长时间不返回的问题。
- 修复 RapidOCR 会话未释放、缓存未区分世界观和上下文、抓屏后端配置不生效的问题。
- 自身窗口遮罩考虑目标窗口的前后顺序，减少误遮盖。
- 新配置默认显示完整译文；已有用户可将“悬浮层”的“最大行数”设为 0。
- Windows OCR 的 auto 模式现在显示总耗时。日文游戏建议直接选择日语识别。
- 安装只接受空目录或已登记目录；卸载只移除安装文件，保留用户另行放入的文件。
- 密钥改用 Windows 当前账户加密保存，旧明文配置自动迁移；增加清除密钥按钮。
- 增加单实例限制、回归检查和 Windows CI；精简界面和说明文案。

## 下载与升级

- `GuGuGaGaTranslator-Setup-1.2.0.exe`：安装版。请退出旧程序后，直接覆盖安装到原来的登记目录。
- `GuGuGaGaTranslator-win-x64-1.2.0.zip`：便携版。请完整解压，保留旁边的 `models` 文件夹。
- `SHA256SUMS-1.2.0.txt`：下载文件的 SHA-256 校验值。

API Key 仍在本机配置中保存，但内容已加密。跨电脑或跨 Windows 账户使用配置时，需要重新填写密钥。旧版本无法读取新版本加密后的密钥，不建议降级覆盖同一配置。

安装包仍未代码签名；PrintWindow、混合 DPI 和游戏兼容性取决于系统与目标程序，不能保证所有游戏均可捕获。
