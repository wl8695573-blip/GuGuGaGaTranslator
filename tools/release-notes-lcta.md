# LCTA 1.6.1

本次更新软件图标。

- 使用长方形“边·译”字标，去掉外围黑边，保留两个字交接处的上下黑色块。
- 桌面和任务栏图标外围透明，提供七种尺寸；主界面、首次设置和安装器同步使用紧凑字标。
- 保留 1.6.0 的多模型、目录迁移与缓存设置，沿用已有配置、密钥和个人术语。

## 下载与升级

- 安装版：`LCTA-Setup-1.6.1.exe`。退出旧程序后安装到原登记目录。
- 便携版：`LCTA-win-x64-1.6.1.zip`。完整解压，运行 `LCTA/LCTA.exe`，保留 DLL、模型与词库。
- 校验值：`SHA256SUMS-1.6.1.txt`。

Windows 图标容器仍使用方形尺寸，但显示主体为长方形；外围留白透明，不拉伸字体。系统图标缓存可能使旧图标暂时保留，重新创建快捷方式可刷新显示。

本次完成图标资源生成与 Release 构建。翻译功能的既有检查记录见 `docs/VERIFICATION.md`；未把历史测试结果作为本次重新测试的结果。
