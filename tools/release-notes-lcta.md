# LCTA 1.6.0

本次完善悬浮入口、模型接入、保存位置和翻译缓存。由 GuGuGaGaTranslator 延续开发，已有设置与个人术语继续保留。

## 更新内容

- 悬浮入口直接显示透明底“边·译”图标，去除黑边和表面 `×`。拖动调整位置，点击菜单选择“关闭悬浮球”。
- 增加通义千问、Gemini、LM Studio 预设，保留 DeepSeek、GLM、硅基流动、Ollama、Sakura 和自定义兼容接口。可读取模型列表，也可手动填写；切换服务时清除旧密钥。
- 数据目录可迁移到其他磁盘，原目录保留为备份。缓存、日志、导出、更新下载、调试证据和 OCR 模型目录可自行选择。
- 缓存增加总开关、内存容量、上下文匹配、命中率、清理过期与分别清空操作。默认只存内存、区分上下文；磁盘缓存使用当前账户加密。
- 修复缓存读入内存后过期时间被延长、旧请求可能重新写入已清空缓存等问题，完善路径错误和迁移取消的处理。
- 首次设置窗口适配较小桌面；原生运行库放在程序目录，减少运行时向系统临时目录解压。

## 下载与升级

- 安装版：`LCTA-Setup-1.6.0.exe`。先退出旧程序，安装到原登记目录。
- 便携版：`LCTA-win-x64-1.6.0.zip`。完整解压到新目录，运行 `LCTA/LCTA.exe`；保留 DLL、模型和词库。
- 校验值：`SHA256SUMS-1.6.0.txt`。

默认沿用 `%APPDATA%\GuGuGaGaTranslator`。放到 X 盘可在“支持 → 文件保存位置”选择空目录并迁移；已单独指定的外部目录保持原位置。同一 Windows 账户下密钥可继续读取。

服务配置完成后测试连接并点击“应用服务设置”。新增服务使用兼容协议，实际模型权限、网络和费用以服务商账户为准；原生不同协议需兼容网关。

测试使用独立配置、合成窗口与 mock 翻译，未使用用户密钥或发送付费请求。真实游戏、混合 DPI、受保护画面、在线译文质量仍需实际环境验证。检查范围见 `docs/VERIFICATION.md`。
