# LCTA 1.5.0

LCTA 由 GuGuGaGaTranslator 延续开发，名称与“边·译”图标、界面和发行文件统一更新。配置目录仍为 `%APPDATA%\GuGuGaGaTranslator`，升级沿用已有设置。

## 本次更新

- 支持中文、日语、英语、韩语的十二种互译方向，加入韩语专用离线 OCR；自动识别会比较通用和韩语候选。
- 新增可拖动、可关闭、可重新开启的悬浮球，展开主要操作与更新入口。
- 底部字幕提供手动框选和自动预设。保存的手动区域用于后续翻译，自动预设不能覆盖它；旧选区按手动区域保留。
- 默认读取目标窗口，避免其他窗口和悬浮译文污染 OCR；窗口捕获不支持时尝试 PrintWindow，失败时提示恢复窗口或调整模式。
- 新增按方向保存的个人术语。添加、编辑或删除后重新识别当前句；公共档案更新保留个人修改、禁用与删除。
- 加入独立公共词库、版本和 SHA256 清单，支持启动检查、提醒、手动应用及可选自动应用。
- 程序更新支持检查正式版、下载并校验安装包，再由用户启动安装器；更新检查不上传台词、截图或密钥。
- 精简窗口列表和快捷操作，使用灰黑、暖白、橙色配色；修复小尺寸下原文区域被挤没、术语表列宽过窄的问题。
- 修复关闭后重新启动的界面线程异常。沿用此前的悬浮层拖动、关闭、长译文滚动、稳定等待、过期请求取消及候选术语禁用。

## 使用与升级

- 安装版：`LCTA-Setup-1.5.0.exe`。先退出旧程序，安装到原登记目录。
- 便携版：`LCTA-win-x64-1.5.0.zip`。完整解压到新目录后运行 `LCTA/LCTA.exe`。
- 校验值：`SHA256SUMS-1.5.0.txt`。

公共词库在“支持”页更新；当前档案仍以英文、日文及对应中文译名为主，部分历史条目待核对。普通翻译接口不接收术语提示，需要在个人术语中填写旧译名以完成本机校正。

本机检查使用合成样本、独立配置及 mock 翻译，不调用付费翻译服务。真实游戏、混合 DPI 跨屏、独占全屏和在线译文质量仍需按实际环境检查。完整范围见 `docs/VERIFICATION.md`。发行文件未签名，模型与图标来源见 `THIRD_PARTY_NOTICES.md`。
