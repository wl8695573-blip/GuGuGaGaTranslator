# LCTA 1.6.2

本次统一主界面与悬浮球快捷导航的外观。

- 灰色系统标题栏改为深色标题栏，主窗口加上橙色外框。
- 最小化、最大化／还原和关闭按钮沿用主界面配色，保留窗口拖动与缩放。
- 悬浮球菜单加入“边·译”标识、橙色图标、功能分组和更新提示。
- 菜单根据当前屏幕高度限制尺寸，较小屏幕可滚动查看。

## 下载与升级

- 安装版：`LCTA-Setup-1.6.2.exe`。退出旧程序后安装到原登记目录。
- 便携版：`LCTA-win-x64-1.6.2.zip`。完整解压，运行 `LCTA/LCTA.exe`，保留 DLL、模型与词库。
- 校验值：`SHA256SUMS-1.6.2.txt`。

沿用已有配置、密钥与个人术语。

本次完成 Release 构建，并渲染实际 WPF 主界面、最小窗口和导航菜单检查排版。翻译功能的既有检查记录见 `docs/VERIFICATION.md`。
